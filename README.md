SmartInventory :-  Billing and managing  System using .NET core

What it does:
A RESTful API for managing products, warehouses, stock transactions, and automated low-stock alerts with comprehensive reporting.


Tech Stack: • 
.NET 8.0 & ASP.NET Core Web API • Entity Framework Core + SQL Server • MediatR (CQRS pattern) • Hangfire for background jobs • JWT Authentication • FluentValidation & AutoMapper

Architecture Highlights: 
✨ CQRS pattern for scalable read/write separation ✨ Repository + Unit of Work pattern ✨ Feature-based organization ✨ Custom transaction middleware ✨ Automated background job processing

Built with enterprise-level practices focusing on maintainability, scalability, and clean code principles.
